# Web CV — Yassin Kamal Simó

A professional **web-based curriculum vitae** developed using modern HTML5 and CSS3 best practices.  
This project serves both as an academic assignment and as a personal portfolio piece.

The goal was to create a **clean, accessible, responsive, and printable** CV suitable for real-world professional use.

---

## 📌 Project Overview

- Fully responsive web CV
- Semantic HTML5 structure
- Modern CSS (Flexbox, Grid, variables)
- Accessible and readable design
- Optimized for screen and print (PDF export)
- Clean and maintainable codebase

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
  - Flexbox
  - Grid Layout
  - Media Queries
  - CSS Variables
  - Pseudo-elements
- SVG Icons
- Mobile-first responsive design
