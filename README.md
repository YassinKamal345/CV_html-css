# CV Web Profesional — Yassin Kamal Simó

Curriculum Vitae desarrollado en formato web como proyecto académico del CFGS ASIX (Administración de Sistemas Informáticos en Red).

El objetivo del proyecto es aplicar buenas prácticas de desarrollo frontend utilizando **HTML semántico y CSS moderno**, creando un CV claro, accesible, responsive y listo para impresión.

---

## 🧠 Objetivos del proyecto

- Crear un CV profesional en formato web
- Aplicar HTML5 semántico correctamente
- Usar CSS moderno (Flexbox, Grid, media queries)
- Diseñar una interfaz clara, accesible y responsive
- Integrar iconografía y recursos visuales de forma coherente
- Preparar el documento para visualización y modo impresión

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
  - Flexbox
  - Grid
  - Media queries
  - Pseudo-elementos
- **Diseño responsive**
- **Accesibilidad básica**
- **Optimización para impresión**
- Iconos SVG
